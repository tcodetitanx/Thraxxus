# The Engineers - Complete Book Blueprint

## Book Info
- **Title:** The Engineers
- **Subtitle:** A Building Adventure with Animal Friends
- **Format:** 8.5" x 8.5" Lulu.com hardcover
- **Age:** 2-5 years old
- **Total pages:** 30 (cover + 28 interior + back cover)
- **Story pages:** 24 (8 builds x 3 pages each)
- **Image size:** 1536x1024 (wide landscape)

## Characters
- **Mama** — the mother from the reference image
- **Dada** — the father from the reference image
- **Neo** — one of the toddler boys. Always wears GREEN with a big letter **N**
- **Ender** — the other toddler boy. Always wears BLUE with a big letter **E**
- **Wall-E** — the golden cockapoo puppy from the reference image
- *Neo and Ender are always the exact same height*

## Prompt Notes
- A reference image is sent with every request for style and character consistency
- Prompts describe scene, action, outfits, and composition ONLY
- All images are wide landscape format (1536x1024)
- Keep compositions clean and readable — avoid clutter
